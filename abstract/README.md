# SkinSafe AI – Project Abstract

SkinSafe AI is an AI-based platform designed to help consumers understand cosmetic product ingredients and choose products according to their skincare preferences.

The system extracts ingredient names from uploaded product-label images using Optical Character Recognition (OCR). Natural Language Processing (NLP) is used to identify and match ingredients with a database containing their functions and available scientific information.

Based on the user's skin profile, known ingredient allergies, preferences and budget, the platform provides personalised ingredient explanations, highlights documented potential concerns and recommends alternative products.

The objective is to help consumers make more informed skincare purchasing decisions through image processing, ingredient analysis and personalised product recommendations.
