# Datasets

This folder contains the datasets used in the SkinSafe AI project.
## Dataset 1: Open Beauty Facts

Source: https://world.openbeautyfacts.org/

File: en.openbeautyfacts.org.products.csv.gz

Purpose:
- Cosmetic product information
- Product names and brands
- Ingredient lists
